# 文件名导出工具

一个 **免安装** Windows 单文件工具，选定文件夹后递归扫描所有文件，输出 .xlsx 格式的文件清单。

---

## 它能做什么

把任意文件夹（含子文件夹）里的所有文件列成一张 Excel 表格，每条记录包含：

| 字段 | 示例 |
|------|------|
| 文件名称 | IMG_0452.jpg |
| 格式 | .jpg |
| 所在全路径 | D:\照片\2025\IMG_0452.jpg |
| 文件大小 | 1,234 KB |

适用场景：盘点文件夹资产、归档前做文件清单、批量导出目录结构。

---

## 怎么用

1. **下载 exe** — 从 GitHub Releases 页面获取 文件名导出工具.exe
2. **双击运行** — 无需安装，打开即用
3. **选择目标文件夹** — 输入路径或用 [浏览] 按钮选择
4. **（可选）勾选隐藏文件** — 需要包含隐藏文件时打勾
5. **设置导出位置** — 选择保存 .xlsx 的目录，可修改默认文件名
6. **点击 [开始]** — 等待扫描完成，自动生成 Excel 文件

> 扫描过程中会实时显示进度、当前文件路径和已发现文件数量。  
> 导出期间请勿删除、重命名或移动文件。

---

## 免安装

- 单文件 .exe，**无需安装 .NET Runtime**，拿到任何 Windows 10/11 x64 机器上双击即运行
- 不写注册表，不留残留文件
